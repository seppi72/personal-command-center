# CalDAV, not EventKit, for Calendar sync

Calendar sync (pulling Apple Calendar events in, pushing Personal Commitments out) needs to run on the backend server, independent of whether the Mac or iOS app is open — ADR-0001 established that automation lives server-side for exactly this reason. EventKit, Apple's calendar framework, only works from an on-device process with user-granted calendar permission; it has no headless server equivalent. We chose CalDAV against iCloud's CalDAV endpoint instead, authenticated with a server-held app-specific password, so the sync job can run unattended on a schedule. The trade-off is a less ergonomic integration than EventKit would have been on-device — CalDAV means hand-rolling event serialization/parsing rather than using Apple's native APIs — but it's the only option that satisfies the "sync runs even when neither app is open" requirement.
